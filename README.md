# CleanMyTV Rus

Русская версия [CleanMyTV](https://github.com/wingedpanther/cleanmytv) для Windows и macOS. Программа подключается к Android TV / Google TV по локальной сети, отключает ненужные предустановленные приложения и устанавливает главный экран **CleanMyTV Home** без рекламы.

Репозиторий русской версии: **https://github.com/userArturM/cleanmytvrus**.

## Что переведено

- Интерфейс компьютера: подключение и сопряжение, автоматическая настройка, очистка, восстановление, главный экран, настройки ТВ и завершение работы.
- Редактор главного экрана: макеты, приложения, ряды, папки, оформление, обои, погода, визуализатор, кнопки пульта и PIN-код.
- Сообщения операций и основные ошибки, подсказки, подписи доступности, меню приложения и установщик Windows.
- Интерфейс CleanMyTV Home на телевизоре: быстрые настройки, темы, приветствие, медиакнопки и ввод PIN-кода.
- Поиск населённых пунктов и отображение дат на русском языке. Формат часов ТВ соответствует настройке 12/24 часа самого телевизора.

Имена пакетов Android, команды ADB, названия сторонних приложений и оригинальных тем не переводятся. Примечания авторов внешних списков очистки и низкоуровневый вывод Android/ADB могут оставаться на английском. Внешние списки сохраняются без изменений, с проверкой контрольной суммы.

## Скачать или собрать

Готовые опубликованные версии размещаются в [Releases](https://github.com/userArturM/cleanmytvrus/releases). Если релизов ещё нет, откройте [Actions → Build](https://github.com/userArturM/cleanmytvrus/actions/workflows/build.yml): после успешной сборки доступны артефакты `CleanMyTV-Windows`, `CleanMyTV-macOS` и `launcher`.

Наличие исходников в этом репозитории само по себе не означает, что установщики уже собраны. Автоматическая сборка не публикует релизы и не изменяет код репозитория.

- Windows 10/11 x64: `CleanMyTV-Rus-Setup-0.6.1.exe`.
- macOS 13 или новее: DMG для Apple silicon и Intel.
- CleanMyTV Home: Android 9 (API 28) или новее. Очистка доступна и на более старых ТВ.

У сборок нет платного сертификата разработчика. Windows и macOS могут предупреждать о неизвестном издателе.

## Быстрый старт

1. Подключите компьютер и телевизор к одной домашней сети.
2. На ТВ откройте **Настройки → Об устройстве → Сборка** и нажмите OK семь раз.
3. В разделе **Для разработчиков** включите **Отладка по USB**, а также сетевую/ADB-отладку, если она есть.
4. Откройте CleanMyTV Rus, выберите ТВ или введите его IP-адрес. На телевизоре разрешите подключение. Для беспроводной отладки используйте сопряжение по коду.
5. Выберите **Очистить и настроить** либо пройдите отдельные шаги. Проверяйте список отключаемых пакетов: не отключайте функции, которыми пользуетесь.
6. Настройте главный экран. На этапе **Завершение** проверьте перезагрузку, отключите отладку на телевизоре и проверьте закрытие порта 5555.

Подробности: [руководство пользователя](docs/USER-GUIDE-RU.md). Перечень поддерживаемых списками моделей: [KNOWN-DEVICES.md](docs/KNOWN-DEVICES.md).

## Восстановление

Очистка **отключает**, а не удаляет пакеты. Перед первым изменением сохраняется точка восстановления. Кнопка **Восстановить** возвращает записанное состояние. Сохраните файл восстановления, путь к которому показывает приложение.

Штатный главный экран возвращается через **Главный экран → Обзор → Вернуть штатный главный экран**. CleanMyTV Home при этом остаётся установленным.

## Разработка

```bash
npm ci
npm run sync
npm run typecheck
npm run build
npm run home
npm run dev
```

`npm run sync` загружает списки из ревизии, закреплённой в `upstream.json`, и проверяет их хеш. `npm run home` собирает APK и запускает его модульные тесты. Для сборки нужны Java и Android SDK; сценарий может загрузить инструменты в `.cytv-build/`.

```bash
UPSTREAM_DIR=/path/to/cleanyourtv npm test
npm run dist:win
npm run dist:mac
```

Для полного набора тестов `UPSTREAM_DIR` должен указывать на исходники `Gathin23/cleanyourtv` в ревизии из `upstream.json`. Windows-сборку удобнее делать на Windows или в GitHub Actions, macOS-сборку — на macOS.

Версия компьютерного приложения: **0.6.1**. Версия русского главного экрана: **1.5.1-ru**, код версии 16. Идентификатор Android-пакета и исходный публичный ключ подписи сохранены для обновления CleanMyTV Home без удаления настроек. Компьютерное приложение имеет отдельное имя и идентификатор; проверка обновлений направлена в этот репозиторий.
