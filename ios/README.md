# Bitora Android TV для iOS 0.1.0

Нативное приложение для iPhone/iPad (iOS 16+). Подключается напрямую к Android TV по ADB TCP; компьютер или облачный посредник не требуется.

## Работает в этой версии
- Сохранение адреса ТВ и собственного RSA-ключа; подтверждение авторизации на телевизоре.
- Пульт: навигация, OK, назад, домой, меню, громкость и воспроизведение.
- Список установленных пакетов и запуск приложений с доступным экраном запуска.
- Ввод латиницей и открытие настроек ТВ.

Нужна **обычная сетевая отладка ADB**, как правило порт 5555. Сопряжение по коду/TLS не поддерживается. APK-установка, системная очистка и редактор лаунчера из компьютерной версии пока не перенесены. Это отдельная первая iOS-версия, а не полная копия настольной программы.

## Установка
Скачайте `Bitora-Android-TV-iOS-0.1.0-unsigned.ipa`, подпишите своим способом, затем установите на iPhone. Файл без подписи напрямую не устанавливается. Разрешите локальную сеть; при первом подключении подтвердите запрос отладки на ТВ. Если отказали в доступе к сети, включите его в настройках iOS и подключитесь повторно.

## Сборка на Mac
```sh
python3 ios/generate_project.py
xcodebuild -project ios/Bitora.xcodeproj -scheme Bitora -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' -derivedDataPath ios/build CODE_SIGNING_ALLOWED=NO build
mkdir -p ios/build/package/Payload
cp -R ios/build/Build/Products/Release-iphoneos/Bitora.app ios/build/package/Payload/
(cd ios/build/package && zip -qry ../Bitora-Android-TV-iOS-0.1.0-unsigned.ipa Payload)
```

Внешних Swift-пакетов нет. Проект и размеры значков генерируются из исходников и существующего логотипа.

## Проверки
GitHub Actions собирает код, проверяет RSA-подпись и формат Android-ключа, обмен ADB с тестовым сервером (включая ошибки), собирает приложение для устройства и проверяет запуск в симуляторе. Эти проверки не подтверждают работу на конкретном физическом iPhone или телевизоре; такая проверка требует подписи и оборудования пользователя.

Используются Foundation, Network, Security и SwiftUI. Ключ создаётся на устройстве и не входит в IPA. MIT; исходный проект CleanMyTV — wingedpanther.
