# Bitora Android TV 0.7.0

- Новое название Bitora Android TV в интерфейсе компьютера, меню, установщике и главном экране телевизора.
- Новый логотип AT, предоставленный владельцем проекта: значки приложения Windows/macOS, интерфейс, Android-значок и баннер телевизора.
- Обновлён русский пользовательский справочник.
- Сохранены идентификаторы пакетов, совместимость обновления Android-лаунчера и данные прежней компьютерной версии.

## Скачать

- **Bitora-Android-TV-Setup-0.7.0.exe** — установщик Windows 10/11 x64. Включает лаунчер для установки на телевизор из программы.
- **Bitora-Android-TV-Home-1.6.0.apk** — главный экран для Android TV 9 и новее. Рекомендуется устанавливать через программу на компьютере: она выдаёт необходимые разрешения и проверяет переключение главного экрана.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Установщик не подписан платным сертификатом разработчика. Проверки сборки и автотесты не заменяют испытания на вашей модели телевизора. macOS доступна для самостоятельной сборки из исходников; готового DMG в этом релизе нет.

Основано на CleanMyTV от Vivek / wingedpanther (MIT). Авторство, лицензии и ссылки на оригинальный проект сохранены в репозитории.
