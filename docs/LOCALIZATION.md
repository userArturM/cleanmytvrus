# Русская локализация

Исходная версия: wingedpanther/cleanmytv, commit 5d1b90e40294421bc53fa1df8e69566e9fd9b427 (0.6.0).

Внесён перевод статических текстов React, сообщений основной части приложения, Kotlin/Compose-интерфейса и XML-описаний Android. Идентификаторы протокола, ключи конфигурации, имена пакетов, команды оболочки и формат файлов тем сохранены.

`locales/ru.json` и `locales/ru-main.json` — справочные словари первичного перевода для сопровождения. Рабочий интерфейс использует тексты непосредственно в исходниках; переключателя языков в этой версии нет. Исходные комментарии разработчика и документация upstream сохранены на английском.

Переподключение использует `ConnStatus.connectionError`, а не поиск фразы в переведённом сообщении. Тесты проверки текста обновлены для русского языка; проверки поведения, восстановления и безопасности сохранены.

Для настольной сборки изменены имя, идентификатор, адрес репозитория и источник обновлений. Для Android сохранены пакет и исходный публичный ключ подписи, увеличена версия: обновление возможно поверх оригинального Home. Ключ в `resources/signing/cleanmytv.jks` — намеренно опубликованный ключ upstream, не личный ключ пользователя.

Проверка интерфейса на компьютере и сборка не заменяют испытания на настоящем телевизоре. Внешние списки очистки, подписи сторонних приложений и вывод команд Android могут содержать английский текст.

Проверки этой версии: `npm run typecheck` и `npm run build` завершены успешно; полный набор `UPSTREAM_DIR=… npm test` — 148 тестов из 148. Синхронизация 371 списка прошла проверку закреплённого хеша. Локальная сборка APK не завершена: загрузка Gradle недоступна из среды проверки. Проверка на физическом ТВ и визуальный прогон в браузере не выполнены.
